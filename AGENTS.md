# Legatio

Read the canonical [PerishLab delivery governance](https://github.com/PerishLab/.github/blob/main/GOVERNANCE.md)
at work start and again before delivery or Issue closure.

Legatio accepts one clear bounded piece of work through a neutral role and session configuration. It assembles context, runs a local coding agent or a later remote one, carries additional information, observes and controls that run's lifecycle, and returns the result and its evidence.

The product keeps durable records of delegation, execution, and delivery. A local task, session, and attempt are that execution record. They are not a business Issue, and they do not duplicate Issue or Project planning or business acceptance. Returning one agent execution is not the caller accepting its delivery.

This baseline does not yet provide a runtime. The first real implementation introduces the truthful source and release configuration for what it actually ships. Grok is the first prospective backend. Receipt, cancel, and resume on a native agent protocol are not qualified. A control outcome that was not observed stays unknown.

Backend credentials stay in Runseal profile isolation. This repository does not hold them. Use a Radicula primitive when a real caller needs it. This file sets no API or schema.
